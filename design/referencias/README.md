# Referencias visuales

Imágenes de referencia (capturas, inspiración, bocetos) de cómo debería verse la interfaz de Tech2Finance.

- Son guía de estilo, no diseños para copiar: no reproducir marcas, logotipos ni pantallas de bancos o productos reales.
- Nombrar los archivos de forma descriptiva (por ejemplo `dashboard-kpis.png`, `grafico-evolucion.jpg`) y, si hace falta, añadir aquí una línea con qué se quiere tomar de cada una.
- No incluir datos personales ni cuentas reales en las capturas.

El agente `ui-designer` consulta esta carpeta antes de rediseñar pantallas.
