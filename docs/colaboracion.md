# Colaboración

Consulta el [reparto](organizacion.md) y los [contratos](contratos.md). Cada tarea tiene responsable, rama y revisión; coordina los cambios de archivos compartidos.

Los cambios grandes siguen la [regla de revisión con nota y rondas limitadas](agentes.md#revisión-de-pull-requests-grandes).

Todos los cambios se trabajan en ramas y se presentan mediante pull request antes de integrarlos en main.
